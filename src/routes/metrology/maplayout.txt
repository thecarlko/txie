How the folder is organized
Folder names: each tool folder pairs an asset ID with the tool's short name, e.g. BVKL61 (OVL51). The short name tells you the tool type: OVL = overlay, AOI = optical inspection, SEM = scanning electron microscope, RSM = defect-review SEM, DEF = particle inspection, PRF = surface profiler, SAM = acoustic microscope, FPP = four-point probe, MTH = film thickness.
Design Status column: this tracks the facility design packages for fitting each tool into the building (the packages are titled "UT MR2 Tool Fit-Up Design Package"). 50% / 90% IFR means "issued for review" at that stage; 100% IFC means "issued for construction."
Standard subfolders. Most tool folders reuse the same set, so I explain them once here:
50% Review / 90% Review / 100% IFC (or IFC): the fit-up design drawings at each stage, plus change logs (e.g. the Arete Engineering change log in OVL52).
Installation and Qualification: vendor site-prep manuals, facility drawings and floor plans.
Pedestal → Vibration Testing: reports from the vibration consultant (Prateek Kulkarni) showing whether each tool's support stand meets the tool's vibration limit.
SOPs: a standard set of eight slide decks, numbered 00–07: Basic Tool Info, Basic Operation, Data Collection, EMO Recovery, Error Identification, Principle of Operation, Qualification, Reset & Recovery. Indu created them all on Feb 23. The previews of several non-Archer decks still say "Archer AP," so many look like copied templates that haven't been filled in. Some tools also have newer Word SOPs from Christopher and Alvin, which look like real content.
Final Acceptance Data / Test: vendor conformance test documents (CTDs), signed acceptance forms, and internal "T2 qualification" summaries.
Post Install CPMs: Evelyn created all of these on Jul 21 at the same time. I didn't open them, and nothing inside them came up in search, so they may be empty placeholders.
Spare Part Lists: spare-parts lists from Manuel, dated May 28.
PC Qual: particle-count checks at 60 nm and 120 nm, with a summary deck for each.

Shared folders (not tied to one tool)
All_Metro_SPC_MR2 is an automated tracking system for SPC (statistical process control: routine checks that each tool's measurements stay in spec). David and Chelsea built it.

Update_MR2_SPC_Dashboard.bat starts the update. It runs a script in work/, which follows pipeline_config.json to rebuild TIE_MR2_SPC_Trend_Monitor.html, the trend dashboard (last rebuilt Oct 27).
README_PORTABLE_SPC.txt says the update works from any computer, but only one person per site at a time. .spc_update.lock is the file that enforces that.
MR2_Metrology Particles.xlsx (Evelyn): a particle tracker.
Per-tool folders: BVKL81_OVL51, LVKL61_OVL52, MBCT61_AOI52, MDKL61_DEF52, MDKL81_DEF51, MSSX61_SAM51, MTKL61_MTH52, plus MTH53, a tool that has no folder of its own here.
